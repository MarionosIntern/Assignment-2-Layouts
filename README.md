# Assignment-2-Layouts

Project Description: This a fully repsonsive UNCG Event Guide webpage that allows students, faculty, and locals to enjoy UNCG events.

Layout Decisions: 
    - A flexbox for my header on index.html. I wanted to put my logo on the opposite end of the page and the flexbox is the first thing I thought of
    - A grid for my upcoming events. Since they were represented as "event cards", a grid allows me to manipulate them freely while maintaining cohesiveness 
    - A flexbox for my footer. I wanted to emmulate the way webpages respond to verying screen sizes and how the footer content usually wraps around. 
     - A grid for my event spotlight info. To display notes on the side of the page while the main content displays descriptive event informaion.
     - A flexbox for my related events section. Smaller, more easy-to-see event cards were displayed and a flexbox allowed for user appeal and quick info.  

Responsive Design: On index.html, the main grid for upcoming events became a breakpoint. I tested the grid sizes and seperation. The navigation  also became a breakpoint to test the links from same page sections and other pages. 


Semantic HTML: 
    - Header: Its the introductory content at the top of the page that repeats
    - Nav: It contained navigation links to other parts of the webapage, internally and externally from the document
    - Aside: It was a sidebar for my grid that contained "key notes" or "side" information to distinguish itself from main content
    - Footer: It contained my closing content, including contact info and copyright statement
